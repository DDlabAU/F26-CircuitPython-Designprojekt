# CPX første testkode

Kopiér `code.py` til roden af `CIRCUITPY` på en Circuit Playground Express.

Formål:
- Bekræfte at board kører CircuitPython.
- Bekræfte serial output.
- Bekræfte LED/NeoPixel respons.
- Bekræfte at `adafruit_circuitplayground` library findes.

Forventet resultat:
- Du ser statusbeskeder i serial console.
- NeoPixels blinker i farver.
- Rød onboard LED toggler.
