# QT Py første testkode

Kopiér `code.py` til roden af `CIRCUITPY` på et QT Py ESP32-S3 board.

Formål:
- Bekræfte at board kører CircuitPython.
- Bekræfte serial output.
- Bekræfte onboard lysrespons (NeoPixel eller LED).
- Give hurtig status på typiske STEMMA-afhængigheder.

Forventet resultat:
- Du ser statusbeskeder i serial console.
- Onboard lys blinker i mindst tre farver eller on/off mønster.
